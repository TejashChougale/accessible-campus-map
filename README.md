# Accessible Campus Map

A beginner-friendly web application that helps students, visitors, and people with accessibility needs navigate college buildings.

## Problem Statement

Finding classrooms, laboratories, departments, faculty offices, and accessible facilities inside a college can be difficult, especially for new students and visitors.

## Our Solution

Accessible Campus Map provides searchable room information, interactive floor plans, highlighted indoor routes, and verified accessibility information in one place.

## Key Features

- **Room Search:** Find classrooms, laboratories, departments, and faculty offices.
- **Interactive Floor Plans:** View rooms and facilities on a building map.
- **Route Highlighting:** Display a route from a selected starting point to a destination.
- **Accessibility Information:** Locate ramps, lifts, accessible washrooms, drinking water, and seating.
- **Issue Reporting:** Report incorrect room details or accessibility problems.
- **Admin Dashboard:** Manage room details, maps, and facility information.
- **Multi-Floor Support:** Add more floors as verified floor plans become available.
- **Responsive Design:** Support mobile phones, tablets, and computers.

## Getting Started

1. Clone this repository.
2. Install the required dependencies.
3. Configure the project according to the setup instructions.
4. Run the development server.
5. Open the application in your browser.

## Important Notes

- Begin with one floor and a small number of rooms.
- Use accurate, verified floor plans and facility information.
- Clearly distinguish verified accessibility information from unverified reports.
- The initial version will use a selected starting point rather than indoor GPS.
- This project is a prototype; route information should be checked for real-world accessibility before being relied upon.
